# Как запустить сайт онлайн (GitHub Pages + Supabase)

Сайт будет по адресу вида `https://ваш-логин.github.io/matematika/`.
Учитель входит по почте, ученики — по логину и паролю, которые выдаёт учитель.
Всё бесплатно. Займёт около 30 минут. Регистрации и пароли делаете **вы** — я их не создаю и не вижу.

---

## Шаг 1. База данных Supabase

1. Откройте **supabase.com** → **Start your project** → зарегистрируйтесь (можно через GitHub).
2. **New project**:
   - Name: `matematika`
   - Database Password: придумайте сложный и **запишите** (нужен редко, но восстановить нельзя)
   - Region: **Central EU (Frankfurt)** — ближайший к Казахстану
   - нажмите **Create new project**, подождите 1–2 минуты.
3. Слева **SQL Editor** → **New query** → откройте файл `app/supabase/schema.sql`, скопируйте **весь** текст, вставьте → **Run**. Должно быть «Success. No rows returned».
4. Слева **Authentication** → **Sign In / Providers** → **Email**:
   - **Confirm email** — **выключите** (см. ниже «Почему»), сохраните.
5. **Authentication** → **URL Configuration**:
   - Site URL: `https://ваш-логин.github.io/matematika/`
   - Redirect URLs → Add URL: тот же адрес.
6. **Project Settings** → **API Keys** (или **Data API**): скопируйте два значения:
   - **Project URL** — вида `https://abcdxyz.supabase.co`
   - **anon public** (или **Publishable key**, начинается с `sb_publishable_`)

   ⚠️ **Никогда** не копируйте `service_role` / **Secret key** — ни в сайт, ни мне, ни в GitHub.

**Почему выключить подтверждение почты.** Бесплатная почта Supabase отправляет письма только участникам проекта (то есть вам) и не больше нескольких в час. Другие учителя письмо не получат и не смогут войти. Без подтверждения учитель регистрируется и сразу входит. Если позже захотите письма (сброс пароля для всех учителей) — подключите свою почту в **Authentication → Emails → SMTP Settings**.

## Шаг 2. Репозиторий на GitHub

1. Зарегистрируйтесь на **github.com** (если ещё нет).
2. **New repository**: имя `matematika`, тип **Public** (бесплатные GitHub Pages работают только для публичных), **без** README → **Create repository**.
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**, две переменные:
   - `VITE_SUPABASE_URL` = Project URL из шага 1.6
   - `VITE_SUPABASE_ANON_KEY` = anon / publishable key из шага 1.6
5. Пришлите мне **адрес репозитория** (например `https://github.com/ваш-логин/matematika`) и напишите, что можно отправить код. При первой отправке Windows откроет окно входа в GitHub — войдите сами.

После отправки GitHub сам проверит ответы и правила базы, соберёт сайт и опубликует его (вкладка **Actions**, 2–3 минуты).

## Шаг 3. Первая проверка (обязательно)

1. Откройте сайт → **Я учитель → Регистрация учителя** → войдите.
2. **Ещё → Классы и ученики** → создайте класс → добавьте одного тестового ученика → распечатайте/перепишите логин и пароль.
3. Откройте сайт в **другом браузере или в режиме инкогнито** → **Я ученик** → войдите тестовым логином.
   - Вошли — всё работает.
   - Ошибка вроде «Database error» — напишите мне текст ошибки: это место я не мог проверить без вашего проекта.
4. Учитель: **Учителю** → создайте варианты → **Выдать классу**. Ученик: **Мои задания** → решите → «Результат отправлен учителю». Учитель: **Журнал результатов** — результат на месте.

## Что важно знать

- **Персональные данные детей.** Хранятся только имя, логин и класс ученика (ни почты, ни телефона). Но это всё равно персональные данные на сервере за рубежом (Германия) — согласуйте с администрацией школы и получите согласие родителей.
- **Каникулы.** Бесплатный проект Supabase «засыпает», если им не пользоваться 7 дней. Данные не теряются: зайдите на supabase.com и нажмите **Restore project**.
- **Резервные копии** на бесплатном плане не скачиваются. Важное (журнал) сохраняйте: в журнале есть кнопка выгрузки CSV.
- **Лимиты бесплатного плана**: 500 МБ базы, до 50 000 пользователей в месяц — для школы этого с запасом.
- **Ключи**: anon/publishable ключ публичный по замыслу — он есть в коде любого сайта на Supabase. Что кому видно, решают правила в базе (проверены автоматическим тестом: ученик видит только себя, учитель — только свои классы, без входа не видно ничего).
- **Офлайн-файл** `Математика.html` продолжает работать без интернета, как раньше (без аккаунтов).
