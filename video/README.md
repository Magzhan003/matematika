# Видеоуроки — как сделать новое видео

Каждое видео — это **сценарий** (`episodes/*.js`): части урока, фразы для голоса на казахском и русском
и что появляется на экране во время каждой фразы. Всё остальное делает общий движок.

## Шаги

```bash
python tools/narrate.py episodes/fractions-add.js kz      # голос (Piper) + тайминг фраз
node tools/rec.cjs episodes/fractions-add.js kz --shots    # проверочные кадры в out/shots
node tools/rec.cjs episodes/fractions-add.js kz            # полное видео → out/fractions-add-kz.mp4
```

То же самое с `ru` для русской версии.

## Как устроен сценарий

```js
{
  say: { kz: ['фраза 1', 'фраза 2'], ru: ['фраза 1', 'фраза 2'] },   // одинаковое число фраз!
  pauseAfter: { 1: 5 },                                               // пауза 5 с после фразы 2
  build(S, E) {
    E.tex('\\dfrac{1}{2} + \\dfrac{1}{3}', { x: 960, y: 400, size: 80 }).write(S.at(0), 1)
    E.pie({ x: 400, y: 450, r: 150, parts: 2 }).show(S.at(1)).fill(S.at(1, 0.5), 0, 1 / 2, E.C.blue)
  },
}
```

- `S.at(i, доля)` — момент внутри фразы `i` (0 — начало, 1 — конец), `S.after(i)` — конец фразы.
- Элементы: `E.tex` (формула KaTeX), `E.text`, `E.pie` (круг-дроби: `fill`, `recut`, `half`),
  `E.cross` (красный крест), `E.ring` (обводка ответа), `E.card`, `E.countdown`.
- Действия: `show`, `write` (появление «как пишут»), `hide`, `move`, `pulse`, `color`.
- Формат: `fmt: 'wide'` — 1920×1080 (урок), `fmt: 'tall'` — 1080×1920 (шортс).
- Числа в голосе пишем **словами** («екіден бір», «одна вторая») — так синтезатор читает правильно.

## Где что лежит

- `engine/` — страница сцены, движок, KaTeX.
- `episodes/` — сценарии.
- `tools/` — голос (`narrate.py`), запись (`rec.cjs`).
- `out/` — тайминги, кадры и готовые видео (в Git не попадают).
- Голоса Piper: `C:\Users\user\piper`, рабочие звуковые файлы — `C:\Users\user\vtmp`
  (Piper не работает с путями на кириллице).
